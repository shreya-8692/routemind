# RouteMind — frontend

React + Vite client for RouteMind. See the [project README](../../README.md) for setup, architecture and testing.

```bash
npm install
npm run dev        # http://localhost:5173 (proxies /api → http://localhost:5000)
npm run dev:https  # HTTPS on your LAN IP, for testing real GPS on a phone
npm run lint
npm run build
```
